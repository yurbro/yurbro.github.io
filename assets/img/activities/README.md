# Conference photograph archive

This folder stores personally owned photographs approved for public display on the academic website.

To add photos:

1. Upload compressed JPG/WebP images here (suggested: 1600 px wide or less; remove location metadata if undesired).
2. Edit `_data/academic_activities.yml` and add items to the relevant event's `photos:` list:

```yaml
photos:
  - src: /assets/img/activities/chisa-2026-01.jpg
    alt: Poster presentation and conference venue
    caption: CHISA 2026, Prague
```

Only add accurate captions, and confirm permission before publishing photographs of identifiable other people. Avoid unpublished slide/data content.
