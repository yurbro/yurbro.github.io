# Yu Zhang - Academic Website

Source for [yurbro.github.io](https://yurbro.github.io), my academic homepage and research portfolio.

The site presents my work on AI-enabled skin product formulation design, dermal drug delivery, active learning, experimental decision-making, interpretable modelling and scientific LLM systems.

## Main sections

- **About** - research vision, programme and background
- **Publications** - peer-reviewed outputs generated from BibTeX
- **Projects** - research code and reproducibility materials
- **GitHub** - selected open repositories
- **CV** - education, experience, outputs and technical expertise
- **Teaching** - University of Surrey teaching support

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The site is based on the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and deployed through GitHub Pages.
